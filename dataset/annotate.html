Karmi — naksa annotation tool SYNTHETIC

Labels one approved drawing + its site photos. Offline, single file. Exports sidecar JSON (core/observe.py format) and a dataset record (dataset/schema.py format). Never put real names or contact details into any field — use opaque ids.

from the drawing scale (e.g. a 1:100 CAD export ≈ 0.025 m/pt at 72 dpi). All exported geometry is in metres.
