Karmi (कर्मी) — low-fidelity wireframes

Hand-authored design artifact for the repository and the demo video. Static: no JavaScript, no external assets, opens standalone. The three core screens are shown side by side: Upload, Results and the Verify list — with the real Nepali labels. Grey dashed boxes are wireframe scaffolding, not final styling; the coloured chips are the real status / severity / confidence vocabulary at the values specified in ui-spec.md §4–5.

Values shown map to core/schema.py (v0.1.0): DiffReport.summary · DiffReport.deltas[] · Delta.status / severity / confidence · VerifyItem.item_np / why / how · DiffReport.limits · ObservedState.stage · SceneGraph.warnings. Examples are illustrative; a real run renders its own data.
